# 구글 클라우드에서 "내가 직접 학습시킨 AI 모델"도 쓸 수 있게 됐습니다

## What

구글 클라우드(Vertex)는 기본 제공 AI 모델 말고도, 회사나 개인이 자기
데이터로 추가 학습시킨 "맞춤 모델(tuned model)"을 따로 배포할 수 있게
해줍니다. 그런데 지금까지 이 SDK는 그런 맞춤 모델을 인식하지 못했습니다.
이번 변경으로 맞춤 모델도 기본 모델과 똑같이 바로 사용할 수 있게 됐습니다.

## Where

`packages/google-vertex` — 구글 Vertex AI와 통신하는 부분을 담당하는
패키지입니다. 그 안에서도 요청을 어느 주소로 보낼지 결정하는
`google-vertex-provider-base.ts` 파일 하나가 이번 변경의 핵심입니다.
사용 예시 코드와 문서도 함께 추가됐습니다.

## How

구글 클라우드는 기본 모델과 맞춤 모델을 서로 다른 인터넷 주소(endpoint)로
받습니다.

- 기본 모델: `.../publishers/google/models/모델이름:generateContent`
- 맞춤 모델: `.../endpoints/엔드포인트ID:generateContent`

이번 변경은 사용자가 모델 이름을 적을 때 `endpoints/`로 시작하는지만
검사해서, 맞춤 모델이면 자동으로 두 번째 주소로 요청을 보내도록
분기했습니다. 우체국 비유를 들면, 지금까지는 모든 편지를 "본사 주소"로만
보냈는데, 이제 편지 앞에 "지점 배송"이라고 적혀 있으면 알아서 해당
지점으로 보내주는 것과 비슷합니다. 사용자 입장에서 할 일은 모델 이름
자리에 `googleVertex('endpoints/내엔드포인트ID')`라고 적는 것뿐입니다.

## Why

구글 클라우드 쪽에서 맞춤 모델 기능 자체는 이미 존재했지만, 이 SDK가
그 주소 체계를 몰라서 못 쓰는 상태였습니다 (연결된 이슈 #6084). 작성자는
실제로 `gemini-2.5-flash`를 학습시켜 엔드포인트에 배포한 뒤, 이 기능으로
직접 텍스트 생성을 시켜보고 정상 동작을 확인했다고 밝혔습니다. 즉, "이미
구글이 제공하는 기능인데 SDK가 못 따라가고 있던 격차"를 메운 변경입니다.
