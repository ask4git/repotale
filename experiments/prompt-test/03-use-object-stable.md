# 1년 넘게 "실험 중"이라 적혀 있던 기능이, 정식 기능이 됐습니다

## What

React·Vue·Svelte에서 AI가 만들어주는 구조화된 데이터(예: JSON 형태의
알림 목록)를 화면에 스트리밍으로 보여주는 기능이 있습니다. 이 기능은
2024년 6월 처음 나온 뒤로 계속 이름 앞에 `experimental_`(실험적)이라는
꼬리표를 달고 있었습니다. 이번 변경으로 이 꼬리표가 떨어지고, 정식 기능
이름(`useObject`, `StructuredObject`)으로 승격됐습니다.

## Where

`packages/react`, `packages/vue`, `packages/svelte` 세 패키지 모두에
같은 작업이 적용됐습니다. 기존에 쓰던 `experimental_useObject` 같은
이름은 없어지지 않고 "이제 이거 대신 새 이름 쓰세요"라는 안내(deprecated
표시)와 함께 그대로 남아있어서, 기존 코드가 갑자기 멈추는 일은 없습니다.
관련 문서 3곳과 예제 코드 4곳도 새 이름 기준으로 같이 업데이트됐습니다.

## How

새 기능을 만든 게 아니라 "이름표만 바꿔 단" 작업에 가깝습니다. 기존
`experimental_useObject` 함수 옆에 이름이 없는 `useObject`를 새로 내보내고
(export), 기존 이름은 "곧 없어질 예정이니 새 이름을 쓰라"는 표시만 붙여서
남겨뒀습니다. 그리고 새 이름과 옛 이름이 완전히 똑같이 동작하는지
확인하는 테스트도 새로 추가했습니다.

식당 비유를 들면, 오랫동안 "시범 메뉴"라는 이름표를 달고 팔던 메뉴를
정식 메뉴판에 올리면서, 옛날 이름표가 붙은 주문서도 당분간은 그대로
받아주는 것과 비슷합니다.

## Why

PR 설명에 따르면 이 기능은 이미 "성숙했고, 문서화도 잘 되어 있고, 널리
쓰이고 있는" 상태였습니다. 즉 실력은 정식 기능인데 이름표만 "실험적"으로
남아 있어서 사용자들이 "이거 써도 되는 거 맞아?"하고 불안해할 수 있는
상황이었던 겁니다. 이 변경은 더 큰 계획(이슈 #16562의 "졸업 전략")의
일부로, 다음 정식 버전(v8)에서 옛날 이름을 완전히 제거하기 전 중간
단계입니다. 작성자는 실제로 예제 앱을 띄워서 새 이름으로 임포트한 코드가
알림 카드 3개를 스트리밍으로 정상 렌더링하는 것까지 확인했습니다.
